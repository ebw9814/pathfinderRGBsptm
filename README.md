# RGB 모의 분광광도계

아이오딘-아이오딘화 칼륨 용액으로 발색시킨 녹말 용액의 사진에서 RGB 값을 읽어, 녹말 농도를 추정하는 웹앱입니다. 분광광도계 없이 녹말의 분해 정도를 비교하기 위해 만들었습니다.

## 사용 방법

`index.html`을 브라우저에서 열면 됩니다. 설치할 것은 없습니다.

1. **사진 불러오기**로 용액 사진을 올립니다.
2. 사진에서 재려는 용액 한가운데를 누르면 번호 원이 생깁니다.
3. 사진에 녹말 0% 기준 용액이 함께 있으면 측정값 표에서 그 줄의 **기준으로**를 누릅니다. 없으면 저장된 기준 색으로 계산합니다.
4. **농도 그래프**와 **색 비교**에서 각 용액의 위치를, **측정값** 표에서 흡광도와 추정 농도를 확인합니다.

## 계산 원리

- 원 안의 픽셀 중 가장 밝은 15%와 가장 어두운 15%를 빼고 평균합니다(반사, 그림자 제외).
- 카메라의 sRGB 값을 빛의 세기에 비례하도록 선형으로 바꿉니다.
- 흡광도 = −log₁₀(시료의 R ÷ 기준의 R)
- 농도는 표준용액의 (농도, 흡광도) 점 사이를 이어서 읽습니다.

## 기본 표준 색상

종이컵에 20 mL씩 담고 아이오딘-아이오딘화 칼륨 용액을 1방울 넣어, 위에서 한 장에 찍은 사진으로 만들었습니다.

| 녹말 농도 (%) | 흡광도 (R) |
|---|---|
| 0 | 0 |
| 0.005 | 0.119 |
| 0.01 | 0.240 |
| 0.05 | 1.075 |
| 0.1 | 1.552 |
| 0.2 | 2.437 |
| 0.5 | 3.265 |
| 1 | 3.296 |

다른 컵, 다른 용액 양, 다른 조명에서는 맞지 않으므로, 조건이 바뀌면 **표준 색상과 설정**에서 새로 등록해야 합니다.

## 한계

- 믿을 만한 범위는 녹말 0~0.1%입니다. 0.2% 이상은 사진에서 거의 검게 찍혀 구분이 어렵습니다.
- RGB 채널은 파장 폭이 넓어 실제 분광광도계의 흡광도와 숫자가 같지 않습니다. 같은 조건에서 만든 표준과만 비교해야 합니다.
- 기준 용액 없이 찍은 사진은 조명과 노출 차이가 그대로 오차가 됩니다.
- 원의 위치에 따라 값이 달라지므로 항상 용액 한가운데를 누릅니다.
